ได้จากการนำโค้ดใน gas/Code.gs ไปสร้าง Web App ใน Google Sheet (Access: Anyone)
info ขั้นตอนการเชื่อมต่อ 3 นาที:
  1. เปิด Google Sheet แล้วไปที่ ส่วนขยาย (Extensions) > Apps Script
  2. คัดลอกโค้ดจากไฟล์ gas/Code.gs ไปวาง แล้วกด Save
  3. กด ทำให้ใช้งานได้ (Deploy) > รายการปรับใช้ใหม่ (New deployment) > ประเภท: เว็บแอป (Web App) เลือกสิทธิ์เข้าถึง: ทุกคน (Anyone)
  4. คัดลอก URL ของเว็บแอป มาวางในช่องด้านบน แล้วคลิก บันทึก URL
  5. ใส่ LINE Notify Token ในแท็บ "ตั้งค่าระบบ & LINE Token" ใน Google Sheet เพื่อเริ่มรับแจ้งเตือน!
